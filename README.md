# user-balance-service

Тестовое задание, сервис хранит балансы пользователей в леджере с двойной записью, команды (зачисление, списание, холд,
подтверждение и отмена холда, перевод) приходят через Kafka, и на каждую уходит событие, стек PHP 8.4, Symfony 8.1,
PostgreSQL 18, Kafka 4.4

## Как запустить

Нужны Docker с Compose v2 и make

```bash
make init
```

Поднимутся PostgreSQL, Kafka, Kafka UI на http://localhost:8080 и воркеры, все команды показывает `make help`

## Как попробовать

```bash
make send t=balance.credit k=1 m='{"operationId":"a0000000-0000-4000-8000-000000000001","userId":1,"currency":"EUR","amount":"100.00"}'
make send t=balance.hold k=1 m='{"operationId":"b0000000-0000-4000-8000-000000000002","userId":1,"currency":"EUR","amount":"30.00"}'
make send t=balance.capture k=1 m='{"operationId":"c0000000-0000-4000-8000-000000000003","holdId":"b0000000-0000-4000-8000-000000000002"}'
make send t=balance.transfer k=1 m='{"operationId":"d0000000-0000-4000-8000-000000000004","fromUserId":1,"toUserId":2,"currency":"EUR","amount":"50.00"}'
make balances
make events
```

## Тесты

```bash
make qa
```

Проверка стиля, PHPStan, unit и интеграционные тесты, интеграционные идут на PostgreSQL из Testcontainers, а Kafka в
тестах заменена на in-memory транспорты
